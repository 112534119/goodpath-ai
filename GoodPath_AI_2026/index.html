作品簡介

GoodPath AI（善行導航）以「做好事、說好話、存好心」及「給人信心、給人歡喜、給人希望、給人方便」為核心，透過善行媒合、友善溝通練習、任務管理及成果紀錄，協助使用者將善念轉換成日常可執行的行動。

需要被解決的問題

想幫助他人，卻不知道從哪件小事做起。

AI 的應用

依個人情境生成行動建議，並協助改寫衝突語句。

人本設計

行動由使用者自主選擇，完成與否由使用者回報。

社會價值

降低參與公益與友善互動的門檻。

AI 使用與資料透明聲明

本機模式：使用人工設計的任務資料庫、條件排序與用語規則，非生成式 AI，不會上傳輸入內容。

AI 模式：伺服器環境設定 API 金鑰後，經使用者明確勾選同意，才將相關文字及偏好送至後端，再由 AI 模型生成任務建議或溝通示範。回傳內容由程式驗證與顯示來源模式，不保證每項建議都適用。

資料存放：未登入時善行紀錄存於本機瀏覽器；登入後可同步至伺服器 SQLite 資料庫。本系統不提供位置追蹤或真實公益組織串接；請勿將示範任務當作已核實的志工服務機會。

成果驗證：使用者自行回報完成狀態；作品不宣稱獲得實際 NGO 認證或量化社會效益。

參賽前請補充：實際 AI 模型名稱、API 供應商、生成內容的人工審核及素材來源與權利確認；並實地測試 API 串接。
