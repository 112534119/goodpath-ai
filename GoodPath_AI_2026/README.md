# 善行導航 GoodPath AI — 2026 參賽進階版

參賽類別：大專組 B 類「AI 數位應用實作類」

團隊成員：楊恩愷、黃婕庭、林韋辰、黃聖翔（分工待確認）

## 快速體驗

1. 不用安裝任何套件：雙擊 `index.html` 即可使用**本機示範模式**：善行規則推薦、友善文字範例改寫、任務日誌、個人成果統計、CSV/JSON 匯出與匯入。
2. 完整網站（含後端伺服器）：安裝 Node.js 22.13+；打開專案資料夾的終端機，執行 `node server.js`，再瀏覽 `http://localhost:3000`。
3. **真正的生成式 AI（選用）：**在啟動伺服器之前，於伺服器環境設定 `OPENAI_API_KEY`；例如 macOS/Linux：`export OPENAI_API_KEY='你的金鑰'`、Windows PowerShell：`$env:OPENAI_API_KEY='你的金鑰'`，然後執行 `node server.js`。金鑰絕不能寫進前端 HTML、JS 或公開儲存庫。
4. 只有當後端金鑰配置成功，且使用者在個別功能勾選「同意傳送資料」，才會將推薦偏好/文字送往生成式 AI。否則依舊可使用本機規則功能。

## 已實作功能

- 完整響應式網頁與 PWA 安裝資訊、離線快取
- 依時間、主題、位置篩選及排序預設善行任務
- 可選擇由生成式 AI 提供「候選任務理由與實踐提示」（伺服器端串接，需金鑰）
- 友善溝通建議（本機規則式示範／可選 AI 改寫）
- 自主認領任務、完成紀錄、心得、完成率、分類統計
- 可匯出 CSV / JSON；可匯入 JSON 備份；可清除本機紀錄
- AI 使用與個人資料傳輸說明、四位團隊成員介紹

## 技術架構

`HTML/CSS/Vanilla JS → Node.js 原生 HTTP API → SQLite（node:sqlite）`；未登入可使用 localStorage 離線示範，另可選 `OpenAI Chat Completions API`。

這是具備**實際 API 串接程式碼**的版本，但是否能成功呼叫模型，取決於競賽現場/部署環境、個人 API 金鑰與供應商服務。未實際測試有效金鑰前，**不得宣稱 AI 服務已通過正式實測**。

## 合法、倫理及限制

- 不提供真實志工時數、正式志工媒合、實名身分認證或已驗證 NGO 職缺。
- 成果數據是使用者自行回報的練習紀錄，不能代表實際公益成效。
- 不鼓勵輸入身分證、電話、地址、病歷等個資；AI 輸入需使用者每個功能勾選同意。
- AI 回應可能不準確，所有行動需使用者判斷其可行性與安全性。
- 本機資料由瀏覽器保管；清除網站資料可能造成紀錄消失，請使用 JSON 備份。
- AI 供應商會依其政策處理提供的文字，正式對外部署前須補上完整隱私政策與使用條款。
- OpenAI 模型名稱可於 `OPENAI_MODEL` 變更，須確認選用模型支援 JSON 格式。

## 部署注意

- GitHub Pages 可部署純靜態頁面**只有本機規則示範**；GitHub Pages 不會執行 `server.js`，不能使用 AI API。
- 若要實際生成式 AI，請部署至提供 Node.js 的主機（或自行改寫成 Serverless function），將 `OPENAI_API_KEY` 設為平台的**秘密環境變數**。
- `.env.example` 僅為欄位示例，Node.js 此版不會自動讀取 `.env`，需自行在執行環境設定。

## 3.0 新增：會員與 SQLite 資料庫

- **需求：Node.js 22.13 以上**（使用內建 `node:sqlite`，無需 npm 安裝）。
- 在專案根目錄執行 `node server.js`，再開啟 `http://localhost:3000`。
- 左側「會員資料庫」可建立帳號、登入、上傳本機紀錄、載入伺服器紀錄、登出。
- 成功登入並選擇資料來源後，善行日誌更動會同步到 SQLite。
- 資料庫位置：`data/goodpath.sqlite`，**由伺服器首次啟動自動建立**，不附帶個人資料。此資料夾不應部署到網站公開目錄或提交 GitHub。請定期備份整個 data 資料夾。
- 資料表：`users`、`sessions`、`records`。密碼使用隨機鹽與 scrypt 雜湊，token 僅以 SHA-256 雜湊存庫，登入有效期 7 日。
- 重要：**這是可測試的開發版會員系統，尚未做登入限速、HTTPS 自動化、忘記密碼、CSRF 全面安全審查、正式隱私政策及正式部署，因此不可直接公開處理敏感資料**。請用測試帳號操作。
- 公開部署需由伺服器保管 SQLite（有持久化磁碟的主機）、開啟 HTTPS，並增加帳號防暴力破解措施。**GitHub Pages 不能執行 Node.js / SQLite**。
- 同步注意：登入時不自動覆蓋既有本機或資料庫資料；請先備份、再決定載入或上傳。多人共享同一帳號不具即時衝突處理。
